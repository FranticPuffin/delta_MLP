这是一个**NASA深空网络(DSN)任务调度系统**的实现，使用**Delta-MILP算法**（改进的混合整数线性规划）在有限天线资源下优化多任务调度。让我详细解释其核心机制：

## 🎯 系统目标

在有限的天线资源（14台）和时间窗口约束下，最大化任务完成度，**高优先级任务在冲突时优先获得调度资源**。

## 📐 核心算法逻辑

### 1. **优先级系统** (1-5级)
```python
PRIORITY_LEVELS = {
    1: "低优先级(常规监测)",
    5: "最高优先级(紧急/不可重访)"
}
```
- 优先级随时间变化（`priority_schedule`字段）
- 目标函数中权重 = 迭代权重 × 优先级²

### 2. **Delta-MILP数学模型**（论文公式6a-6m）

#### 目标函数 (6a)
```python
最大化 Σ(权重 × 优先级² × x_ij)
```
- `x_ij`：二进制变量，表示活动i在第j个窗口是否执行
- **优先级平方**使高优先级任务优势更明显

#### 关键约束
- **6k, 6l**：可拆分任务的两个子任务必须成对调度
- **6m**：原任务与拆分任务互斥
- **资源容量**：总天线使用时间 ≤ 14台 × 168小时 × 70%利用率

### 3. **动态权重调整** (Algorithm 2)

```python
迭代过程：
1. 计算每个任务的满意度 = 实际调度时长 / 请求时长
2. 如果满意度 < 阈值η，该任务权重翻倍
3. 所有任务达标后，提升阈值η
4. 重复最多5次
```

## 🔧 代码结构解析

### 核心类 `DeltaMILPScheduler`

| 方法 | 功能 |
|------|------|
| `_load_data()` | 读取JSONL格式的任务数据 |
| `_get_activity_priority()` | 计算任务在时间窗口内的加权优先级 |
| `solve()` | **MILP求解核心**，定义变量、目标函数和约束 |
| `visualize_and_save()` | 生成甘特图和CSV调度表 |

### 任务活动属性
```json
{
  "activity_id": "观察任务A",
  "d_max": 2.5,        // 最大时长(小时)
  "can_split": true,   // 是否可拆分
  "view_periods": [{   // 可见时间窗口
    "start_hr": 10.0,
    "end_hr": 14.5,
    "antenna": "DSS-14"
  }]
}
```

## 📊 输出分析

运行后会输出：

1. **控制台日志**
   - 每轮迭代的满意度和欠调度任务
   - 最终各任务优先级与满意度对比表

2. **CSV调度表** (`dsn_schedule.csv`)
   - 任务ID、天线、开始/结束时间、准备/拆除时间

3. **甘特图** (`dsn_gantt_chart.png`)
   - 横轴：时间（小时）
   - 纵轴：天线编号
   - 不同颜色代表不同任务

## ⚠️ 当前简化点

1. **窗口选择简化**：`solve()`中只取第一个可见窗口（实际应选最佳窗口）
2. **未考虑天线切换时间**：真实场景中天线在不同任务间需要设置时间
3. **时间离散化**：15分钟粒度可能丢失精确窗口边界
